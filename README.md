# Desa Wisata Banjaran - Smart Tourism Platform

**Website Link:** https://desawisatabanjaran.infinityfreeapp.com/

## About Project

A centralized web application designed to digitalize tourism village operations. It transitions manual promotion into a modern digital platform, providing a dynamic catalog for tour packages and streamlining the booking process. The system integrates a Generative AI chatbot to serve as a 24/7 virtual assistant capable of answering context-specific queries regarding the tourism packages.

## Main Features

- Digital Tourism Catalog: Centralized display of tour packages and local galleries.
- AI Virtual Assistant: Integrated Google Gemini API to provide instant responses to visitor inquiries based on local database context.
- Automated Administration: Admin dashboard for real-time order validation and automated PDF transaction reporting.
- Single Sign-On (SSO): Secure user authentication via Google OAuth 2.0.
